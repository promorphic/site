Shown in the streams figure under "The universal layer", in the agents' own colours. Files are used as published; do not edit or recolour.

| File | Source | Note |
|---|---|---|
| `claude.svg` | Anthropic press kit (anthropic.com/press-kit), Claude icon, square | Official file |

| `kimi-on-light.svg`, `kimi-on-dark.svg` | Moonshot AI branding guide (moonshotai.github.io/Branding-Guide), K-only, light and dark | Official files, one per theme |

Each mark belongs to its owner and is used under that owner's terms. Showing a mark says only that an agent of that kind can act through the layer; it claims no relationship.
