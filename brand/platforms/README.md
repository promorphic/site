# Tokenization platform marks

Used in the streams figure under "The universal layer". Each platform has two files: `-on-light` for the light version of the site, `-on-dark` for the dark one. Third-party marks: they say where an agent can act, never who is a customer or partner. Do not recolour beyond the black/white pair each owner publishes.
